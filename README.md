# karchertapijtreinigerhuren.nl

Statische Nederlandstalige verhuurwebsite voor een Kärcher tapijtreiniger.

## Bestanden

- `index.html` — pagina-inhoud, huurprijzen, toepassingen en SEO-metadata.
- `style.css` — responsive vormgeving, productpresentatie en toepassingenraster.
- `script.js` — mobiele navigatie, automatisch jaartal en WhatsApp-linkconfiguratie.
- `assets/` — productfoto en geoptimaliseerde foto's van textiele toepassingen.

## Zelf invullen voor publicatie

- Vul `whatsappNumber` in `script.js` met je nummer inclusief landcode, alleen cijfers (bijvoorbeeld `31612345678`). De WhatsApp-knoppen verwijzen zolang het nummer leeg is naar het contactgedeelte.
- Vervang in `index.html` het element `.photo-placeholder` door een `<img>` met je eigen geoptimaliseerde foto.
- Controleer of `https://karchertapijtreinigerhuren.nl/` het juiste live domein is voor de canonical URL.

Open `index.html` in een browser om de website te bekijken.
